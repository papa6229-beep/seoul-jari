# 서울자리 MVP 작업 기준

## 판단

서울자리는 `supot` 복제본을 바로 넓히되, 실제 추천 점수는 데이터가 연결된 범위에서만 보여준다. 현재 즉시 분석 가능한 업종은 학원·교습소이고, 카페·분식·피트니스·무인점포는 데이터 원천을 먼저 연결한 뒤 점수화한다.

## 서비스 범위

- 지역 범위: 서울 한정
- 사용자: 서울에서 자영업 창업 후보지를 찾는 사람, 부동산·상권 상담자
- 1차 화면: 업종 선택, 지역 검색, 서울 후보지 비교, 업종별 체크리스트
- 금지선: 창업·투자·계약의 최종 판단처럼 보이는 표현

## 업종 확장 순서

1. 학원·교습소
   현재 복제본 데이터가 있으므로 즉시 데모 가능하다.

2. 개인 카페
   가장 대중적인 창업 후보지만 경쟁과 임대료 영향이 크다. 상가업소, 생활인구, 역세권, 주거·오피스 혼합도를 먼저 붙인다.

3. 분식·김밥·샌드위치
   반복 수요와 점심·학생 동선이 중요하다. 학교·학원·오피스·배달 반경을 함께 본다.

4. 필라테스·PT
   주거 인구, 퇴근 동선, 지불 여력, 건물 시설 조건을 따로 본다.

5. 무인점포
   임대료와 관리 리스크가 중요하다. 야간 유동·민원·치안성 신호는 데이터만으로 단정하지 않는다.

## 데이터 원천 후보

- 소상공인시장진흥공단 상가업소정보: 업종별 기존 점포와 경쟁 밀도
- 서울 열린데이터광장 생활인구·교통·도시데이터: 시간대별 수요와 유동 보조지표
- 국토교통부 실거래가 및 기존 보유 부동산 요약: 지불 여력과 임대료 부담 보조지표
- 학교알리미·교육 관련 공개자료: 학원·교습소 업종의 수요 보조지표
- 지하철역·버스정류장 공개자료: 접근성과 동선 보조지표

공식 확인 메모:

- 서울 열린데이터광장은 OpenAPI 사용을 위해 인증키 발급 절차를 안내한다. https://data.seoul.go.kr/together/guide/useGuide.do
- 공공데이터포털에는 소상공인시장진흥공단 상가정보 관련 공지가 있고, 상가업소정보를 공공데이터로 다룬다. https://www.data.go.kr/bbs/ntc/selectNotice.do?originId=NOTICE_0000000002194
- 서울 실시간 도시데이터는 주요 장소의 인구·교통·주차 등 정보를 제공한다. https://www.data.go.kr/data/15146211/openapi.do

## 구현 단계

1. `business-types.json`을 기준으로 업종 목록과 데이터 상태를 한 곳에서 관리한다.
2. 상가업소 CSV를 서울만 필터링해 동 단위 업종 수로 집계한다.
3. 생활인구·교통 데이터를 동 또는 역세권 단위로 붙인다.
4. 업종별 점수는 하나의 총점보다 `수요`, `경쟁`, `비용`, `현장 확인` 네 묶음으로 나눈다.
5. 웹에서는 점수를 단정형 문장이 아니라 `강점`, `주의`, `확인 질문`으로 보여준다.

## 사용자에게 필요한 것

- 서울 열린데이터광장 인증키
- 공공데이터포털 `소상공인시장진흥공단_상가(상권)정보_API` 일반 인증키
- 새 GitHub 저장소 이름과 공개 여부
- 유료화 전에 붙일 최소 면책 문구 확인

## 상가 API 수집 방식

- 엔드포인트: `https://apis.data.go.kr/B553077/api/open/sdsc2`
- 1차 사용 기능: `storeListInDong`
- 조회 단위: `divId=signguCd`, `key=서울 자치구 코드`
- 저장 파일: `web/data/store-summary.json`
- 인증키 저장 위치: 로컬 환경변수 또는 GitHub Actions secret `DATA_GO_KR_SERVICE_KEY`
